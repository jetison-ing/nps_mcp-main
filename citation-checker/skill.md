# Citation checker

1. Read every entry in the bibliography the user provides.
2. For each entry, confirm it has an author or organization, a title, a date or "Accessed" date, and a URL ending in a period.
3. Never invent an author or a date. If one cannot be verified, use the organization as author.
4. Return the corrected list, then a short table of what changed and why.
